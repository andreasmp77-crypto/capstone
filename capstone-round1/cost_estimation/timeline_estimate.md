# Implementation Timeline Estimate — Crew Change Risk Copilot

## 1. Purpose

This document outlines the indicative implementation timeline for the **Crew Change Risk Copilot**.

The proposed approach follows a phased implementation model, starting with discovery and strategic planning before progressing through solution design, MVP development, testing and final pilot review.

The timeline is designed for a focused MVP and controlled pilot rather than a full enterprise production deployment.

---

# 2. Key Timeline Assumptions

| Assumption | Description |
|---|---|
| Project duration | Approximately 12 weeks |
| Project approach | Phased MVP and controlled pilot |
| Scope | Focused Crew Change Risk Copilot use case |
| Delivery model | Lead Consultant supported by EU-based freelance specialists |
| Data availability | Pilot data is available and reasonably prepared |
| Enterprise integrations | Limited during the pilot |
| UI approach | Lightweight interface using Streamlit or similar framework |
| Stakeholder involvement | Regular access to operational users and decision-makers |
| Development approach | Lean MVP focused on core functionality |
| Deployment scope | Controlled pilot rather than enterprise-wide deployment |

> **Important:** The 12-week timeline represents elapsed project duration and does not assume full-time utilisation of every team member throughout the project.
